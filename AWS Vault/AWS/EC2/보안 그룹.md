#### [[EC2]] 단위 가상 방화벽

- 외부에서 내부로(인바운드), 내부에서 외부로(아웃바운드) 나가는 트래픽 허용 설정
- 트래픽 거부 지정 불가 (허용 규칙만 존재)
- 각 IP 혹은 보안그룹을 기준으로 트래픽 허용 설정 가능
->EX) 보안그룹 B or 10.0.0.1 IP에 대해 80 포트 허용
- 서브넷 단위 방화벽(네트워크 ACL) 이후 사용하는 2차 방화벽

- 상태를 기억하는 Stateful 성질
--> 인바운드에서 허용된 트래픽은 응답이 나갈 때에도 허용되는 특징
-> 요청에 대한 응답 != 아웃바운드
