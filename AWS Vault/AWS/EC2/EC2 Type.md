#### EC2 인스턴스 유형 파악

ex) t2.micro
- t : 인스턴스 클래스 (유형)
- 2 : 인스턴스 세대
	 - 특정 유형 인스턴스에 대한 개선시 업데이트
- micro : 인스턴스 크기 의미

1. 범용 인스턴스
- 다양 작업에 적합 (웹 서버 등)
- 컴퓨터, 메모리, 네트워크가 균형잡혀 구성됨
- t or m 클래스

2. 컴퓨터 최적화 인스턴스
- 고성능 cpu 탑채
-  고성능 서버, 머신러닝 구성시 사용
- c 클래스로 시작됨 (cpu)

3. 메모리 최적화 인스턴스
- 고성능 메모리 탑재
- 대규모 데이터 처리에 장점
- R 클래스로 시작됨 (RAM)

1. 스토리지 최적화 인스턴스
- 로컬에서 대규모 데이터에 접속 시 사용
- db에서 고빈도 요청 반복 처리에 장점
- D클래스로 시작(DB)
