1. 온디멘드 :  원하는 때에 전체 가격 지불하여 EC2 대여, 
	-> 단기 사용에 이점

2. 예약 : 특정 기간 동안 미리 대여 (할인)
	-> 1년, 3년 기간으로 예약 가능, 장기 사용 이점

3. 전환형 예약 : 특정 기간 후 인스턴스 타입 변경 가능

4. 절약 플랜 : 특정 사용량 만큼 비용 지불 (인스턴스 아님)
	-> 1, 3년 기간으로 예약
	-> 사용량에 대해 예약하는 방식
	-> 할인 + 비용 초과시 온디멘드 약정 부여
	
5. 스팟 인스턴스 : 미사용 인스턴스 대한 경매 진행 (최대 할인)
	-> 현재 스팟 가격이 지정 최대 가격 초과 시 제거될 수 있음
	-> 제거 및 복구가 자유로운 기능에 대해 사용, 단기 사용에 이점
	-> 중요 db와 같이 안정적 운영 필요 시 사용 금지
	
	-> 스팟 인스턴스 제거시 **스팟 요청 취소 -> 인스턴스 제거** 순으로 진행
	-> 인스턴스 우선 제거할 경우 스팟 요청이 인스턴스 추가 실행 가능
	-> open, active, disable 상태에만 요청 취소 가능 
![[스팟 인스턴스 요청 종료 이미지.png]]
5. 스팟 플릿 : 스팟 인스턴스 세트 정의 방식 (선택적 온디맨드)
	-> 지정된 가격 제한에 대해 목표 용량을 맞추기 위해 사용
	-> 다양 인스턴스 타입 고려하여 적절한 방식 찾음 (목표 or 비용 도달까지)

		1. 최저 가격 옵션 (적은 비용, 짧은 사용 시)
		2. 다양화 옵션(diversify) : 다양 풀로 분산 (고가용성, 긴 사용 시)
		3. 용량 최적화 : 원하는 인스턴스 수에 맞춰 제작
		4. 가격 용량 최적화 : 원하는 용량 전체 검색 -> 가장 낮은 가격 풀 선택 (대부분 적합)

-> 원하는 인스턴스, AZ 알고있는 경우 : 스팟 인스턴스
-> 특정 조건 만족하게 인스턴스 제작할 경우(ex 비용, 용량) : 스팟 플릿

7. 전용 호스트(dedicated host) : 자신만의 실제 서버 대여
	-> 기업 규정에 따라 전용 서버 필요 시 적합
	-> 물리적 코어, 소켓 가시성 기반 비용 책정
	
8. 전용 인스턴스(dedicated instance)
	-> 나만의 하드웨어에 나만의 인스턴스를 구성함
	-> 타 고객과 하드웨어 공유 x 의미
	

10. 용량 예약 : 특정 기간동안 용량 예약, 미사용 기간 존재 시 사용
