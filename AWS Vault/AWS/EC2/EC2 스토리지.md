#### EBS, EFS

- EBS - 인스턴스 실행 중 연결 가능한 네트워크 드라이브 
- EC2 종료해도 볼륨 유지 가능 (일종의 usb로 이해)
- 기본적으로 동일 가용영역 내의 EC2와 연결 가능
- 스냅샷 사용시 타 가용영역에도 연결 가능
- EC2 생성과 함깨 생성 시 EC2 종료 및 함께 삭제 기능 지원
- -> 중단 없이 용량 증가 가능, 백업 용이
- 기본적으로는 1 인스턴스에 적용되나 io타입은 다중 인스턴스에 연결 가능 (동일 AZ한정)


- EFS - 여러 인스턴스에 연결되는 파일 저장 시스템
	- EBS와 달리 타 AZ 인스턴스에 대해서도 다중 연결 지원
	- 리눅스 기반 AMI에만 적용 가능
- -> 자동 용량 확정 축소 가능, 다양 리전에 복제되어 안정성 높음
