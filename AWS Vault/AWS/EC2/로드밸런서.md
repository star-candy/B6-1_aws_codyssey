### 여러 인스턴스에 들어오는 트래픽을 균등 배포하는 기능

- AWS에서는 Elastic Load Balancer 서비스로 기능 제공
- EC2와 통합하여 고가용성, 확장성 유지 가능
- 보안 및 에러 발생 시 대처 용이 (확장시에도 1회만 인증, 특정 EC2에러에도 정상 동작 유지 등)


- 인터넷 백팅 옵션 생성 시 외부 인터넷 요청 받기 가능 (인터널 시 private ip만 사용 가능)
- 리스너(인바운드), 라우터(요청에 대한 응답) 설정 필요
- Target group 생성으로 라우팅 대상 지정 가능
- -> 이때 정상 응답여부에 대한 확인 진행
- -> Target group register target에서 로드 밸런싱 대상 인스턴스 지정

- 이후 로드밸런싱 대상 인스턴스 보안그룹이 로드밸런서 요청을 받도록 수정 필요
