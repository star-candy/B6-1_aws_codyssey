#### 인스턴스 배치 방식 제어

##### 1. 클러스터 배치 그룹
- 하나의 가용영역에 모든 인스턴스 배치
- 속도 빠름, AZ장애에 취약함
- 빅데이터 등 속도 중요 인스턴스에 사용

##### 2. 분산 배치 그룹
- 인스턴스를 각 하드웨어 별로 분산 배치
- 배치그룹, 가용영역 당 인스턴스 7개로 제한
- 고가용성, 배치 그룹 규모에 제한 발생 문제
- 적당한 크기에 안정적 인스턴스에 사용

##### 3. 분할 배치 그룹
- 파티션을 통해 인스턴스 분할
- 가용영역당 최대 7개 파티션 가능
- 각 파티션에 여러 인스턴스 추가 가능 (용량 문제 해결)
- 파티션(랙) 분할로 실패를 분리 가능 + 용량 문제 해결
