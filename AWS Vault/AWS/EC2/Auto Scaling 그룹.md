#### 시스템 상에서 지원하는 자동 수평 확장 기능
- cpu, 메모리의 특정 상태 도달 시 수평 확장 자동 수행
- [[로드밸런서]]와 함께 사용
- 확장 시점 관리를 위한 특정 정책 사용됨

1. 동적 크기 조정 정책 (그룹 지표에 따른 인스턴스 수 조정)
	- 대상 추적 크기 조정(특정 수치가 50% 사용량을 유지하도록 조정)
	- 단순 크기 조정(특정 수치 넘으면 확장, 내려가면 축소)
	- 단계 크기 조정 (단계별로 크기 조정)
2. 예약된 조정 정책 (특정 시간, 이벤트 발생 전에 조정)
3. 예측 크기 조정 정책 (트래픽 패턴 학습 후 상승, 하락 예상 시 조정)

#### 사용 방식
- 실행할 인스턴스 시작 템플릿(AMI) 구성
- 오토 스케일링 그룹 생성으로 인스턴스 자동 확장
- 확장 시 자동 로드밸런서 등록 가능
