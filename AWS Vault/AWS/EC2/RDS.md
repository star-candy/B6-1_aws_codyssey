#### AWS에서 관리되는 관계형 DB 서비스  

- [[EC2]] 인스턴스 내에 DB 생성 시 타 인스턴스와 데이터 공유 안됨(일관성 x)
- 인메모리형 DB (H2)는 인스턴스 종료 시 데이터 삭제 (안정성 x)

- 중단 없이 DB 오토스케일링 가능
- DB복제 통해 안정성, 일관성 유지 가능
- 타 가용영역에 RDS 배포 - 장애 처리 이점 - Multi AZ
- 읽기 트래픽 분산으로 가용성 향상 가능 - 읽기 전용 복제본
- RDS 프록시 통해 RDS 트래픽 분산 및 장애 처리 속도 향상 가능


- RDS 사용 시 파일은 저장 불가
- 각각의 인스턴스에 저장되기에 파일 데이터의 일관성 유지 불가 문제 발생
