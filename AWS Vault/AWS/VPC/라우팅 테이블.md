#### 서브넷 트래픽을 전달하는 방식을 정의하는 테이블
- 각 테이블은 [[서브넷]]에 연결
- 퍼블릭 서브넷의 테이블은 [[인터넷 게이트웨이]]에 라우팅 됨 
-> (인터넷 게이트웨이와 연결된 테이블을 가진 서브넷은 퍼블릭 서브넷)
- 프라이빗 서브넷의 테이블은 [[NAT 게이트웨이]]에 라우팅 됨
-> (NAT 게이트웨이는 퍼블릭 서브넷에 위치, 라우팅 테이블은 프라이빗 서브넷에 배치)

- 생성 시 서브넷에 라우팅 테이블 연결 후 게이트웨이에 라우팅 할 것
-> destination을 0.0.0.0/0으로 모든 IP 지정, target을 게이트웨이로 지정
