#### VPC 내에서 외부 인터넷과 통신하기 위한 서비스
- 외부에서 내부 리소스 접근 불가능(인터넷 게이트웨이와 차이)
- private ip 통한 요청 시 ip를 중간에 변환하는 기능 - 보안 유지 가능
- 생성 시 외부 인터넷과 연결 위한 Eliastic IP 할당 필요
-> 프라이빗 서브넷 ip 유출 없이 인터넷과 통신 위한 고정 IP 생성
- 비교적 비용이 높은 서비스이므로 NAT instance 고려할 수 있음

- NAT 게이트웨이 자체는 퍼블릭 ip 가짐 - 퍼블릭 서브넷에 배치 (외부 인터넷과 통신 위함)
-> NAT 게이트웨이의 라우팅 테이블은 프라이빗 서브넷에 배치
