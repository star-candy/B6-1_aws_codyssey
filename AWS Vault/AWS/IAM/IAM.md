#### 사용자 생성 및 관리 서비스 (글로벌)

- 리전에 종속되지 않는 글로벌 서비스
- 각 사용자에 대해 그룹 지정 및 역할 지정 가능
- -> 최소 권한 원칙 따를것 (필요한 역할만 제공한다.)

- 각 그룹에는 사용자만 지정 가능 (그룹에 그룹 지정 불가)
- 그룹에 [[권한 정책]]을 지정하고 해당 그룹에 사용자를 추가하는 방식으로 활용
- 각 서비스에 권한 부여할 경우  **IAM Role** 사용
- ->ex) ec2에 IAM Role 부여

- 1. 비밀번호 정책 구성 (길이, 변경, 재사용, 특수문자 등)
