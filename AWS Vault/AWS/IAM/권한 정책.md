#### 그룹 혹은 사용자에게 역할 할당하는 기능

- 그룹에 지정된 권한은 그룹에 속한 사용자에게 상속됨
- 작성 시 정책 구조에 맞게 설정 필요

![[정책 구조 이미지.png]]
- version : 정책 언어 버전
- Statement : 내부에 각 상태 지정함
	- Effect : Statement의 접근 가능 여부 판단
	- Principal : 정책 적용 대상
	- Action : Effect 상태에 따라 허용, 거부되는 영역
	- Resource : 적용될 Action의 리소스 목록

-> Resource 영역에 대해 특정 Action을 Effect한다로 이해할 것
